# Projet_Immobilier Master 2 Data Science
Application de gestion immobilière pour un réseau d'agences.
Ce projet vise à développer une application web permettant de gérer les vendeurs, acheteurs et agents immobiliers, tout en suivant les différentes étapes des transactions immobilières. Étapes du projet:
 1. Dans votre présentation :
 • un modèle relationnel des bases de données.
 • les modèles django correspondants.
 2. Développez l’application dans un projet git collaboratif en respectant les bonnes pratiques.
 3. Utilisez les outils vus lors du cours (pandas, SQL, django, ...).
